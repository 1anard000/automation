The Business — 30 Seconds

What Dify is (3 points):

  1. Open-source platform for building AI agent workflows visually — no code required
  2. Sits between AI models (GPT, Claude, Llama) and business systems (CRM, databases)
  3. 280+ enterprise customers including Maersk, Adobe, Novartis, Deloitte, PayPal

How Dify makes money (3 tiers):

  1. Community Edition — free, self-hosted. Top of funnel. No revenue.
  2. Dify Cloud — managed SaaS. $590-$1,590/yr. Subscription revenue.
  3. Enterprise — custom ($50-200K+/yr). SSO, VPC, audit, SLAs. High-ACV contracts.

Same model as GitHub: Open-source core drives adoption. Managed cloud and enterprise features drive revenue. GitHub converted 180M free users → $2B+ ARR. Dify has 1.4M installations.

Opening — "Tell me about yourself and why Dify?"

"Three roles converge at Dify:

Amazon — I helped APAC sellers across Southeast Asia, Korea, and Taiwan reach Western consumers. That's GTM for Asian companies going international. Dify faces the same trust gap.

GitHub/Microsoft — I watched open-source PLG convert to enterprise revenue. I was there when Copilot launched — an AI product on an open-source platform. That's exactly what Dify is building.

Salesforce — I learned how enterprises buy software. The committee decision, the security reviews, the compliance gates.

I was originally skeptical of AI platforms — the model layer has unsustainable economics. But Palantir's thesis convinced me. Karp said models produce 'strings of text' without enterprise grounding. What you need is an 'intermediate representation of the enterprise that AI can interact with.' That's Dify."

Product Strategy — 3 Points

Where Dify is going (3 layers):

  1. Build (today) — Visual workflow builder, RAG pipelines, agent creation. ✅ Shipped.
  2. Collaborate (next 12mo) — Team workspaces, Human Input Node, audit trails. 🔄 In progress.
  3. Ecosystem (18-36mo) — Creator Center, Template Marketplace, third-party integrations. 🔄 Early.

What makes Dify defensible (3 moats):

  1. Open-source trust — Enterprises audit the code, self-host, no vendor lock-in. Critical for Chinese-origin company going West.
  2. Model-agnostic — Any LLM. More valuable as models fragment. Lets enterprises optimize cost.
  3. Data grounding — MongoDB + Voyage AI integrations create switching costs. Model-agnosticism is table stakes; data-agnosticism is the next moat.

Product strategy talking points (3):

  1. Absorb frameworks, don't compete. Git → GitHub. LangChain → Dify. Frameworks commoditize. Platforms compound. But the window is closing — LangChain is building its own platform (LangGraph).
  2. Human Input Node = Trojan Horse for governance. Workflows pause for human review → audit trails → compliance without heavy RBAC. Bottom-up governance.
  3. Content-led enterprise motion. Three research pieces in 6 weeks targeting IT leaders. Not blog posts — sales enablement material for CIOs.

GTM Strategy — 3 Motions

Motion 1: PLG (months 1-3)

  1. Generous free tier drives developer adoption (130K+ GitHub stars)
  2. Developers bring tool to work → team adopts → enterprise needs compliance
  3. Key metric: free → paid conversion rate (target: 2-5%)

Motion 2: Enterprise Sales (months 3-9)

  1. Sales play: "Your developers are already using Dify. Let's make it official."
  2. Different buyers need different value props (developer ≠ IT leader ≠ CFO)
  3. Remove objections: security, compliance, governance, support

Motion 3: Partner Channel (months 6-12)

  1. APAC: System integrators (Accenture, Deloitte, PwC — already using Dify)
  2. US: AI consultancies and developer agencies
  3. Partner margin: 30-40% wholesale discount

Competitive Landscape — 3 Layers

The competitive landscape has three layers. Each is a different type of threat.

Layer 1: Platform Competitors (big companies)

  1. n8n — 196K stars (more than Dify). Open-source, visual, 400+ integrations. But: not AI-native (AI is add-on). Biggest direct threat.
  2. Google Gemini EAP — Enterprise benchmark (80% Codability). Deepest security. But: Google-locked, not accessible.
  3. Microsoft Copilot Studio — Dominant by distribution (Office 365 bundle). But: Azure-locked, proprietary.

Layer 2: Framework Competitors (moving up)

  1. LangChain / LangGraph — 141K stars. Now brands as "agent engineering platform" (not just framework). LangGraph Platform = cloud-hosted agent deployment. Moving into Dify's territory.
  2. Dify should absorb LangChain (like GitHub absorbed Git), not compete. But the window is closing.
  3. Frameworks commoditize — LangChain, CrewAI, AutoGen all converging. Platforms compound.

Layer 3: AI Coding Agents (different category)

  1. Claude Code — Anthropic's coding agent. Proprietary, cloud-only, locked to Claude. Not a Dify competitor — it's a developer tool, not a workflow platform.
  2. Cursor — AI code editor. Same — developer productivity tool, not workflow orchestration.
  3. GitHub Copilot — AI pair programmer. Complementary to Dify (helps build workflows), not competing.

These are tools for developers writing code. Dify is a platform for teams deploying AI workflows. Different layers.

Also: Acquired Competitors

Flowise → Workday. Stack AI → Asana. Pipedream → Workday. 3 of 8 competitors just acquired. Consolidation validates the space. Dify is one of the last independent open-source AI platforms with enterprise traction.

Also: China Competitor

Coze (ByteDance) — Multi-agent, enterprise edition, desktop/mobile. Most dangerous in China. But: not open-source, geopolitical risk limits Western adoption.

3 things the CFO cares about:

  1. Cloud vs. self-hosted mix. Successful open-source companies (Databricks, Confluent, Elastic) get 60-80% from cloud. Where is Dify?
  2. Free → paid conversion. GitHub benchmark: 2-5%. What's Dify's actual rate?
  3. GTM investment efficiency. Rule of 40: growth rate + profit margin ≥ 40%. Palantir hits 47%.

⚠️ Monetization risk:

HashiCorp struggled with open-source monetization → acquired by IBM for $6.4B. Dify needs cloud-first strategy to avoid the same fate.

Risk Factors — "What Could Go Wrong?"

Top 3 risks (with mitigations):

  1. Community Edition cannibalization — Enterprises self-host for free. Mitigation: Make Cloud so good they choose managed. GitHub playbook.
  2. n8n overtaking Dify — More stars, higher scores. Mitigation: Double down on AI-native (RAG, agents) where n8n is weaker.
  3. Hyperscaler "good enough" — AWS/Google/MS bundle AI workflows. Mitigation: Model-agnosticism + open-source trust. Enterprises don't want lock-in.

Questions to Ask the CFO

Pick 3-4:

  1. "What's the biggest gap in Dify's GTM today — awareness, conversion, or sales capacity?"
  2. "What's the cloud vs. self-hosted revenue mix? Where is Dify on the Databricks trajectory?"
  3. "With 3 competitors acquired — is Dify thinking about M&A or building independent?"
  4. "What does the GTM team look like today? Am I the first dedicated hire?"
  5. "What's the most successful enterprise deal? What did the sales process look like?"
  6. "How does the CFO think about GTM vs R&D investment?"
